# IntrusiveInnerVoice

Interactive art-project website with a quiz and visual gallery. I built the whole site, frontend and backend, for the artist behind the project (see `about.html`).

For hosting purposes all .html files and .php initializers are found in the root directory instead of the view & controller containers respectively.
This directory is linked to a hosting platform which requires the above be the case.

The live site (intrusiveinnervoice.ca) is no longer online. More information about the project: https://www.madebymyah.ca/
